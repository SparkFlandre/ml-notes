# Dive into Deep Learning 阅读笔记

---

## 一、基础概念

### 1.1 数据分布与泛化误差

- **样本 ≠ 分布**：你手里的数据是样本；分布是生成这些数据的未知机制 $P(X)$。训练集只是从分布中抽出的有限子集。
- **泛化误差**：模型在真实分布 $P(X)$ 上的期望错误率，永远无法精确计算，只能用测试集估计。
- **经验误差**：模型在训练样本上的平均错误率。
- 核心矛盾：模型可能在训练集上"死记硬背"噪声（过拟合），导致训练误差低但泛化误差高。

### 1.2 优化：从解析解到梯度下降

- 只有少数简单情况（如线性回归）能令 $\nabla L(\theta)=0$ 直接解析求解。
- 深层网络的损失函数高度非凸、参数量巨大，只能通过迭代逼近。
- **梯度下降更新**：
  $$\theta \leftarrow \theta - \eta \nabla L(\theta)$$
  本质是用"感受坡度、一步步走"的数值方法，逼近 $\nabla L(\theta)=0$ 的解。

### 1.3 正则化：约束模型的自由度

在损失函数中加入惩罚项：
$$L_{\text{total}} = L(\theta) + \lambda R(\theta)$$

| 技术 | 机制 | 效果 |
|---|---|---|
| **L2** | $R(\theta)=\|\theta\|^2$ | 权重衰减，决策边界平滑 |
| **L1** | $R(\theta)=\|\theta\|_1$ | 产生稀疏权重，自动特征选择 |
| **Dropout** | 训练时随机关闭神经元 | 强制分布式表示，防共适应 |
| **早停** | 监控验证误差，上升即停 | 防止过拟合后期 |
| **数据增强** | 扩充样本多样性 | 扩大分布覆盖 |

**L2 的闭式解视角**：$\theta^*_{\text{ridge}} = (X^\top X + \lambda I)^{-1}X^\top y$。加上 $\lambda I$ 保证矩阵正定可逆；奇异值分解显示小奇异值方向（噪声方向）被压缩最狠，大奇异值方向（信号方向）基本保留。

### 1.4 协变量偏移

严格定义：**训练与测试数据的输入分布变了，但特征到标签的映射规律不变**：
$$P_{\text{train}}(X) \neq P_{\text{test}}(X),\quad P(Y|X)\text{ 不变}$$

区别于：
- **概念漂移**：$P(Y|X)$ 本身变了；
- **标签偏移**：$P(Y)$ 变了，$P(X|Y)$ 不变。

## 二、从全连接到卷积

### 2.1 多层感知机处理图像的困境

图像输入是二维矩阵 $\mathbf{X}$，若用全连接层把每个输出位置 $(i,j)$ 连到所有输入像素 $(k,l)$，权重需要 4 个下标：
$$[\mathbf{H}]_{i,j} = [\mathbf{U}]_{i,j} + \sum_k\sum_l [\mathbf{W}]_{i,j,k,l}[\mathbf{X}]_{k,l}$$

$\mathbf{W}$ 是四阶张量，参数量为 $(hw)^2$，随图像尺寸爆炸。

**关键观察**：把绝对坐标 $(k,l)$ 改写为相对偏移 $(a,b)$，令 $k=i+a, l=j+b$：
$$[\mathbf{H}]_{i,j} = [\mathbf{U}]_{i,j} + \sum_a\sum_b [\mathbf{V}]_{i,j,a,b}[\mathbf{X}]_{i+a,j+b}$$

下一步引入两个约束，四阶张量就坍缩为卷积核：
1. **平移等变性**：权重不依赖绝对位置 $(i,j)$，只依赖相对偏移 $(a,b)$；
2. **局部性**：偏移只在 $|a|,|b|\leq\Delta$ 的小范围内取值。

### 2.2 通道：特征图的并列组织

- **通道 = 同一空间位置上并列的多份特征描述**。
- RGB 图像是 3 通道；卷积层输出 $C$ 个通道 = 用了 $C$ 个卷积核，每个核横跨输入所有通道，产出 1 张特征图。
- 通道数由**卷积核个数**决定，与输入通道数无整数倍关系（如 LeNet 中 $6\to16$：用 16 个横跨 6 通道的三维核即可）。
- 深层通道语义：浅层对应边缘/颜色，中层对应纹理组合，深层对应部件/概念。

### 2.3 平移不变性 vs 平移等变性

- **等变性**（卷积层）：输入平移，特征图也跟着平移。$Conv(shift(x)) = shift(Conv(x))$。
- **不变性**（池化层 + 分类头）：输入平移，最终分类结果不变。
- CNN 通过"卷积的等变性 + 池化的位置模糊化"近似实现平移不变性，使同一套权重可复用于所有位置。

## 三、经典 CNN 架构演进

### 3.1 LeNet（1998）

- 结构：卷积 → 池化 → 卷积 → 池化 → 全连接
- 关键细节：C1（6 通道）→ S2（6 通道，尺寸减半）→ **C3（16 通道）**。6→16 不是整除关系，而是使用 16 个横跨 6 通道的卷积核，每个新通道都是 6 张低级特征图的加权组合。

### 3.2 AlexNet → VGG

**VGG 的核心改进**：
1. **模块化**：定义 VGG block = $k$ 个 $3\times3$ 卷积（same padding）+ ReLU + $2\times2$ 最大池化。网络变成可堆叠的积木。
2. **小卷积核堆叠**：两个 $3\times3$ 感受野 = $5\times5$，三个 = $7\times7$，但参数更少、非线性更多。
3. **统一节奏**：每过一个 block，空间尺寸减半、通道数翻倍（64→128→256→512）。

代价：VGG 总参数 1.38 亿，大部分集中在全连接层，显存消耗大。

### 3.3 NiN（Network in Network）

- **mlpconv**：普通卷积后接两个 $1\times1$ 卷积 + ReLU。在每个空间位置上运行一个微型 MLP，增强局部非线性。
- **全局平均池化（GAP）**：最后一个 $1\times1$ 卷积把通道数变为类别数，直接全局平均后接 softmax，**彻底消灭全连接层**。
- 遗产：发明了 $1\times1$ 卷积作为标准组件；开创了 GAP 分类头范式。

### 3.4 GoogLeNet / Inception

**设计理念**：用稀疏连接思想指导设计，但用密集并行结构实现。

**Inception 块**：
```
输入
 ├─ 1×1 卷积 ──────────────┐
 ├─ 1×1 → 3×3 卷积 ────────┤
 ├─ 1×1 → 5×5 卷积 ────────┼─ concat → 输出
 └─ 3×3 池化 → 1×1 卷积 ───┘
```

- **多尺度并行**：让网络自适应选择感受野；
- **1×1 瓶颈**：在 3×3/5×5 前压缩通道，控制计算量（如 256→48 后再 5×5）；
- **辅助分类器**：中间层接小分类头，缓解深层梯度消失；
- 参数仅 500 万，精度超越 VGG。

## 四、现代 CNN 核心设计

### 4.1 残差网络 ResNet

#### 问题：退化（Degradation）

网络加深后，**训练误差反而上升**。这不是过拟合，而是非线性层堆叠难以优化到恒等映射。

#### 核心设计

$$y = \mathcal{F}(x, \{W_i\}) + x$$

- 分支 $\mathcal{F}$ 学的是**残差** $\mathcal{F}(x) = \mathcal{H}(x) - x$，而非完整映射；
- 若某层无需工作，只需 $\mathcal{F}\to 0$（权重趋于零），远比让多层非线性合成恒等映射容易。

**Basic Block**（ResNet-18/34）：
```
x → [3×3→BN→ReLU→3×3→BN] → +x → ReLU
```

**Bottleneck Block**（ResNet-50/101/152）：
```
x → 1×1(降维C/4) → 3×3 → 1×1(升维C) → BN → +x → ReLU
```

#### 下采样处的投影捷径

当 $x$ 与 $\mathcal{F}(x)$ 形状不同时（高宽减半、通道加倍），捷径上用 $1\times1$、stride=2 的投影矩阵 $W_s$：
$$y = \mathcal{F}(x) + W_s x$$

绝大多数块使用**零参数的纯恒等捷径**。

#### 矩阵视角

- 单块雅可比：$\frac{\partial y}{\partial x} = I + \frac{\partial \mathcal{F}}{\partial x}$
- 深层梯度回传存在保底项 $I$，即使 $\frac{\partial \mathcal{F}}{\partial x}$ 衰减，梯度仍能无损穿透；
- 连乘展开 $\prod(I+J_i)$ 含 $2^L$ 条隐式路径，网络等价于大量浅网络的集成。

**预激活改进（ResNet v2）**：
将 BN 和 ReLU 移入残差分支内部、相加之前：
$$x \to BN \to ReLU \to [3\times3 \to BN \to ReLU \to 3\times3] \to +x$$
恒等路径 100% 纯净，深层训练更稳定。

### 4.2 稠密网络 DenseNet

#### 核心设计

第 $l$ 层的输入是前面**所有层**的拼接：
$$x_l = H_l([x_0, x_1, \ldots, x_{l-1}])$$

维度演化（设增长率为 $k$）：
- 第 $l$ 层输入通道：$C_b + k(l-1)$
- 第 $l$ 层输出：$k \times H \times W$（空间不变，仅新增 $k$ 通道）

**DenseBlock 内部结构**（瓶颈层）：
```
[拼接输入] → BN → ReLU → Conv_{1×1}(4k 核) → BN → ReLU → Conv_{3×3}(k 核, pad=1)
```

**Transition Layer**（块间连接）：
$$1\times1\text{ 卷积压缩}(\lfloor\theta C\rfloor) \to \text{AvgPool}_{2\times2, s=2}$$

#### 与 ResNet 的本质对比

| | ResNet | DenseNet |
|---|---|---|
| 连接方式 | $x + \mathcal{F}(x)$（逐元素加） | $[x_0, \ldots, x_{l-1}]$（通道拼接） |
| 信息保存 | 相加融合，原信号稀释 | 并列保留，全程可追溯 |
| 梯度路径 | 固定 $I$ 保底 | 每层离损失仅 1~2 层（隐式深度监督） |
| 参数效率 | 高（但全连接层臃肿） | 更高（特征复用，无需重复学习） |

#### 矩阵视角

将 $W^{(l)}$ 按输入来源分块：
$$W^{(l)} = [W^{(l,0)} | W^{(l,1)} | \ldots | W^{(l,l-1)}]$$

第 $l$ 层输出：
$$x_l = \phi\left(\sum_{j=0}^{l-1} W^{(l,j)} x_j\right)$$

整个 DenseBlock 是**分块下三角的非线性变换**，下三角每个非零块都是一条从 $j$ 到 $l$ 的显式通路，共 $L(L+1)/2$ 条连接。

## 五、关键组件详解

### 5.1 1×1 卷积

- **本质**：在每个空间位置上做跨通道的全连接线性组合，不改变空间尺寸。
- **作用**：
  1. **通道降维/升维**（瓶颈）：如 256→64→256，3×3 计算量降为 1/16；
  2. **跨通道信息融合**：卷积核只在空间内混合，通道间靠 1×1 沟通；
  3. **廉价插入非线性**：两层之间夹 1×1+ReLU，低成本加深网络；
  4. **替代全连接**：NiN/GoogLeNet 用 1×1 将通道数变为类别数 + GAP，消灭全连接层。

### 5.2 批量规范化 Batch Normalization

对 batch 内每个通道做：
$$\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}},\quad y = \gamma \hat{x} + \beta$$

- **训练时**：用当前 batch 统计量，同时维护滑动平均 `running_mean/var`；
- **推理时**：用滑动平均统计量，变成确定性线性变换；
- **位置**：通常放在卷积之后、激活之前（或预激活结构中的残差分支内）；
- **核心效用**：
  - 平滑损失曲面，允许使用大 10 倍的学习率；
  - 稳定深层信号传播尺度，与残差连接配合使上百层网络可训练；
  - batch 统计噪声带来隐式正则化效果。

## 六、训练与工程实践

### 6.1 向量化 vs 循环

PyTorch 中逐元素循环慢于张量运算的核心原因：
- **Python 解释器开销**：每次循环都是一次 Python 字节码执行；
- **算子调度开销**：每次 `a[i]+b[i]` 都是独立的算子调用，包含张量元数据检查、kernel 启动；
- **无法并行**：循环是严格串行的；张量运算走 SIMD/GPU 并行。

### 6.2 映射的数学概念

| 概念 | 含义 | 对应 |
|---|---|---|
| **恒等映射** | $f(x)=x$，输出等于输入 | ResNet 捷径 |
| **单射** | 不同输入不同输出 | 信息可区分 |
| **满射** | 值域被全覆盖 | 无遗漏 |
| **双射** | 单射+满射，可逆 | 存在逆映射 |
| **线性映射** | 保持数乘与加法 | 无偏置全连接 |
| **仿射映射** | 线性+平移 | 带偏置全连接、BN 的 $\gamma x+\beta$ |
| **复合映射** | $f\circ g(x)=f(g(x))$ | 多层网络堆叠 |

## 七、架构演进脉络图

```
图像输入
  ↓
LeNet（卷积+池化的雏形，通道作为多特征图）
  ↓
AlexNet（ReLU+Dropout+GPU 训练，深度突破）
  ↓
VGG（模块化 block + 3×3 小卷积堆叠，设计范式化）
  ↓
NiN（1×1 卷积 + 全局平均池化，消灭全连接）
  ↓
GoogLeNet（Inception 多尺度并行 + 1×1 瓶颈，稀疏思想密集实现）
  ↓
ResNet（恒等捷径 + 残差学习，解决退化，深度解放）
  ↓
DenseNet（稠密拼接 + 特征复用，极限利用浅层信息）
```

**核心线索**：从"如何提取特征"（LeNet→VGG），到"如何 cheap 地混合通道"（NiN 的 1×1），到"如何选尺度"（Inception），最终收敛到"**如何训练极深网络**"（ResNet 的恒等保底 vs DenseNet 的全连接复用）。所有现代组件（BN、1×1、GAP、残差/稠密连接）共同回答了同一个问题：**在参数量和计算量受限的前提下，让信息无损地流得更深、更广。**
