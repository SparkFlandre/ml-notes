# SVD

这节感觉是整门课的核心，也最难，看的时候反复暂停。

A = U Σ V^T

U、V 正交（旋转），Σ 对角（奇异值，从大到小排）。降序排很重要，截断靠它。

外积形式：A = σ1 u1 v1^T + σ2 u2 v2^T + ...
每个 u_i v_i^T 是秩1矩阵，σ_i 权重。大概就是"一层一层"？大的是主要信息，小的是细节。这个"分层"的理解我觉得是关键。

Eckart-Young：留前 k 项 = 离 A 最近的秩 k 矩阵，误差 = 后面奇异值平方和。所以降维压缩砍小的就行（跟 PCA 应该有关）。

几何：A 把单位球 → 椭球，轴长 = 奇异值。σ1 = 算子范数 = 最大拉伸。

完整 vs 精简 SVD：完整版 Σ 里有零，对应 U、V 列白算。精简砍掉，省内存稳定，默认用精简。

奇异值谱画出来，"肘部"急剧衰减 = 留几项的分界。

说实话几何那块（旋转-缩放-旋转）还是有点抽象，先记着，后面用到再回来看。
