# PageRank

用线性代数给网页排序，这节挺有意思，例子直观。

邻接矩阵：列→行有边填 1。

按列归一化（每列除以出度）→ 转移概率矩阵，元素 = 随机选一条出边的概率。

状态向量 p0，乘一次 → p1 = A p0，重复 p_k = A^k p0。马尔可夫链，无记忆。

陷阱节点（出度 0）会卡住。解决：随机跳转，概率 α 均匀跳任意节点。Q = (1-α)A + α(1/n)J。

Q 不可约+列随机，Perron-Frobenius 保证唯一主特征值 λ=1，特征向量全正，归一化 = 平稳分布 = PageRank 分数。

五节点例子：节点4 最高 0.439，5 次之 0.328，3 是 0.207，1、2 极低 0.013。

逻辑：被重要页面引用 + 引用重要页面，双向强化。

现代谷歌早不只这个了，但它是基石。
