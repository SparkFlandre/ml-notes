# 反向传播

神经网络怎么训练。单隐层 Sigmoid 平方误差。

损失 L = (1/2)Σ(d̂_ik - d_ik)²（1/2 求导方便）。

两阶段：前向算 h_m、d̂_k，反向算梯度。

链式法则，输出层 v_kl 三重分解：

∂L/∂v_kl = (∂L/∂d̂_k)(∂d̂_k/∂z_k)(∂z_k/∂v_kl)

Sigmoid 导数 σ'=σ(1-σ)，梯度 = (d̂_k-d_k)·d̂_k(1-d̂_k)·h_l。

但这个导数也是梯度消失根源：σ' 最大 0.25，饱和趋零。

误差项 Δ_ik = (d̂_ik-d_ik)d̂_ik(1-d̂_ik)，隐层 γ_mi = Σ Δ_ik v_km h_m(1-h_m)。Δ、γ 是"责任份额"。

更新：v←v-ηΔh，w←w-ηγx。

非凸，局部极小。工程：Mini-batch、标准化、L2。

"前向-反传-更新"通用，换激活函数只需换导数，就是 PyTorch 自动微分根基。

（σ'=σ(1-σ) 这个性质既是方便又是梯度消失根源，一体两面）
