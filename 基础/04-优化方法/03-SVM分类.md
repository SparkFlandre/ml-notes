# SVM

间隔 = 边界到最近样本距离。SVM 找间隔最大的超平面。

推出来间隔 M = 1/‖w‖，所以最大化间隔 = 最小化 ‖w‖²。

直觉：w 是法向量，‖w‖ 大边界陡，对 x 变化敏感，安全区窄。要宽间隔压小 ‖w‖。

加"所有样本函数间隔 ≥1"约束 → 凸二次规划 QP，全局唯一。

支持向量：只有落在间隔边界上的样本决定边界，其余没影响。稀疏。

软间隔：线性不可分时硬约束松弛成铰链损失：

min Σ max(0, 1-d(x^T w+b)) + λ‖w‖²

λ 大重间隔（容忍错误），λ 小重拟合。

（M = 1/‖w‖ 这个反比关系一开始没想通，后来才懂：w 大边界陡）
