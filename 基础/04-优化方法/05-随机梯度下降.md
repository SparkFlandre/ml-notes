# SGD

批量梯度每步 O(Nm) 还要装整个矩阵，数据大不行。

SGD 把总成本拆单样本 f = Σ f_i，每步一个样本 i_k，O(m)。

为什么靠谱？无偏性。随机抽样 E[∇f_ik] = (1/N)∇f。单样本梯度这次错，平均对，长期方向正确。

三种遍历：循环式、随机重排式、真随机式（严格无偏）。

岭回归 SGD：w ← w + τ(d_ik - x_ik^T w)x_ik - τ(λ/N)w
Lasso SGD（次梯度）：w ← w + τ(...)x_ik - τ(λ/2N)sign(w)

梯度噪声反而是特性：逃离浅局部极小 + 隐式正则。

（无偏性那步挺好理解，醉汉走路那个比喻）
