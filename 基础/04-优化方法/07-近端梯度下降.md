# 近端梯度下降

Lasso = 光滑项 + 非光滑 L1，L1 在 0 不可微。子梯度能做但慢，近端梯度更好。

MM 策略（上界最小化）：构造当前点相切、处处不低于原函数的可微上界 g_k，最小化它。

关键一步算子范数不等式 ‖A(w-w_k)‖² ≤ ‖A‖²‖w-w_k‖²，把 ‖Aw-d‖² 松弛成 (1/τ)‖w-w_k‖²。

迭代两步：
1. 梯度步 z_k = w_k - τA^T(Aw_k-d)
2. 近端步 w_{k+1} = argmin ‖z_k-w‖² + λτR(w)

光滑部分梯度，非光滑部分近端算子。R 可分离就逐分量解。
