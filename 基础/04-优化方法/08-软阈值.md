# 软阈值

近端梯度用到 Lasso，近端步 = min ‖w-z_k‖² + λτ‖w‖₁。

L1 可分离，拆成 m 个一维 min (z_i-w_i)² + λτ|w_i|。

解出软阈值：w_i = sign(z_i) max(|z_i| - λτ/2, 0)

- |z_i| ≤ λτ/2：置零（稀疏来源）
- 否则向原点收缩 λτ/2

一句话：把 z_i 朝原点压 λτ/2，压过零归零。弱特征反复压到零，强特征留下。

整个 Lasso = "梯度下降 → 软阈值"循环，最终吸附坐标轴（某分量=0）。

进入 0 邻域就锁死，稀疏模式稳定。

这节公式不多，软阈值那个式子记一下就行。
