# PCA 去噪

（从随机信号角度讲 PCA，跟 SVD 那节角度不同但本质一样）

依据协方差 R 选最优正交基，前 p 大特征值对应特征向量。重构误差 = 砍掉的 N-p 小特征值之和。

SNR 增益：X = S + 白噪声 N（协方差 σ²I）。白噪声各方向均匀 σ²。PCA 把 p 个自由度给信号子空间：
- 原始噪声 Nσ²
- 重构后 pσ²
增益 = N/p。

特征值平移：R_X = R_S + σ²I，谱上移 σ²，高台（信号）+平台（噪声）。平台高度 ≈σ²，高于平台的个数 = 信号维数 p。

例子：128 维 500 次观测，噪声 4 倍信号，前 2 特征值突出，取前 2 维 SNR 提升 64 倍。

三个挑战：p 难定、非白噪声破坏最优、有限样本有偏。

（SNR 增益 N/p 这个结论挺实用）
