# 随机过程 + 平稳性

索引是时间就是随机过程。还是聚焦二阶矩：均值 μ(n)、自相关 R(n,k)。

平稳性 = 统计特性不随时间平移变。
- 严平稳 SSS：所有有限维分布不变（强）
- 宽平稳 WSS：均值恒定 + 自相关只依赖时滞 k

WSS 把 R(n,k) 压成 R(k)，"记忆长度"成内禀属性。

三类平稳过程：
- 随机二进制：均值 0.5，自相关 δ[k]·0.5+(1-δ[k])·0.25
- 白高斯噪声：均值 0，自相关 σ²δ[k]
- 随机正弦：均值 0，自相关 (σ²/2)cos(ωk)

遍历性：时间平均 = 集合平均，只有一段数据能估计的关键。

宽平稳是遍历的必要不充分。

（严平稳 vs 宽平稳的区别搞清楚了，宽平稳就够大部分场景）
