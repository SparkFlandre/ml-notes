# 用内积表示函数

先复习：列向量，转置变行。内积 a^T b = 对应元素乘加 = |a||b|cosθ。

核心：很多函数都能写 x^T w = 0。

- x=[s,t], w=[w1,w2] → s = -(w2/w1) t，过原点直线
- x 加常数 1、w 加 w3 → 控制斜率和截距
- 加 t^3 t^2 t 1 → s 是 t 的任意多项式

内积=0 ⟺ 正交（垂直），cos(π/2)=0。内积 = w 在 x 方向投影。

几何：二维是垂直 w 的直线，三维是平面，n 维是 n-1 子空间。

分类应用：收缩压+胆固醇判断心脏病。x^T w>0 患病，<0 不患病，边界 x^T w=0。直线不够用三次多项式。

这节的点就是"函数 = 特征内积"，这样就能用线性代数工具。感觉后面会反复用。
