# 解的存在性和唯一性

A w = d 先问有没有解，再问唯不唯一。

存在：d 在列空间。rank(A) = rank([A|d]) → 有解。

例子：A 两列 z 分量 0，列空间 xy 平面。d=[-1,1,0] 有解，d=[-1,1,1] 无解。

唯一：列线性无关，rank(A)=n。

为什么相关就无穷多解？两个解 w、w~，f = w~-w ≠ 0，Af=0。f 能任意缩放，w+γf 全是解。

判定表：
- rank(A) < rank([A|d])：无解
- 相等且 rank(A)=n：唯一
- 相等且 rank(A)<n：无穷多

（无穷多解那块是正则化的入口，后面岭回归就用这个）
