# 低秩近似 + 偏差方差

A = 信号 S + 白噪声 G（协方差 σ²I）。

白噪声对 SVD 的影响方向和尺度分离：
- 方向不影响（奇异向量不变）
- 尺度把奇异值都抬 √m·σ

低秩只留前 r 个奇异值，误差拆两部分：
- 偏差² = 砍掉的尾部奇异值平方和（丢了多少信号）
- 方差 = r·m·σ²（留了多少噪声）

r 增大：偏差² 减，方差增，总误差某 r* 最小。

有用没用看奇异值谱：衰减快低秩好；平缓没主导结构，硬降维偏差大。

Scree plot "肘部" = 信号噪声分界。

（偏差-方差这个词后面 md3 交叉验证还会出现，先记住是"简单→偏差大，复杂→方差大"）
