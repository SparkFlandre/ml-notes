# 特征分解 + 幂迭代

特征值/特征向量：B e = λ e。矩阵作用在 e 上只缩放 λ，不转向。

对称矩阵谱定理：B = E Λ E^T（E 正交，Λ 对角）。

SVD 和特征分解桥梁：
- B1 = A A^T，非零特征值 σ_i²，特征向量 u_i（左）
- B2 = A^T A，非零特征值 σ_i²，特征向量 v_i（右）

工程上 n>>m 时 B2 = A^T A 只有 m×m，还能流式累加外积。

幂迭代求 v1：c_k = B2 c_{k-1} / ‖B2 c_{k-1}‖。

收敛到 v1 的原因：c0 = g1 v1 + g2 v2 + ...，每乘 B2 第 i 分量乘 λ_i，k 次后非主分量 (λ_i/λ1)^k 指数衰减。收敛速度由 |λ2/λ1| 决定。
