# 铰链损失

平方误差用分类有缺陷：对所有偏差二次惩罚，不管样本是不是已正确分类。极端值（木星）主导优化，拉偏边界。

分类只看符号（对错）不看数值（准不准），平方误差在优化数值，错位了。

铰链损失 max(0, 1 - d x^T w)，d ∈ {-1,+1}：
- d x^T w ≥ 1：损失 0
- 0 < d x^T w < 1：线性（正确但太近边界）
- d x^T w < 0：线性增长（误分类）

max(0,·) 把已正确分类的压成 0。

零一损失（数错分）非凸不可微，铰链是它的凸近似，代价是 d x^T w = 1 处不可微。

几何：x^T w = ±1 之间是"间隔带"，带内损失非零。
