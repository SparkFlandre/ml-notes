# 拟合 + 矩阵乘法

这节基本是复习矩阵，比较简单。

- 矩阵：数值按行列排。维度先说行再说列，3×2 = 3 行 2 列
- 元素 A(i,j) = 第 i 行第 j 列
- 向量默认列向量，转置变行
- 列向量并排 → 矩阵；转置当行叠 → 正好是前者转置

建模例子：二次多项式拟合分数随时间。每个样本特征 1、t、t^2 排一行，n 个样本 → n×3 矩阵 T。预测 = T w。

多响应（两个品牌车价）：不同响应放不同列 → T W 矩阵乘矩阵。

分块矩阵：分成子块后乘法规则不变，C 第一块 = A11 B11 + A12 B21。前提子块可乘。

维度要求：左列数 = 右行数。A n×m、B m×l → C n×l。C(m,n) = A 第 m 行点乘 B 第 n 列。
