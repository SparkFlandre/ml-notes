# 神经网络入门

神经元 = 线性分类器 + 激活函数：ŷ = σ(x^T w)。

激活函数是唯一非线性来源。没它多层堆叠只是线性复合（线性∘线性=线性）。

激活函数：
- ReLU max(0,z)，梯度恒定缓解梯度消失，默认
- Sigmoid 1/(1+e^-z)，S 型

多层：d̂_m = σ(Σ v_mn σ(Σ w_nj x_j))。深度 = 抽象层级。

通用逼近定理：三层网络足够多隐藏单元，任意精度逼近连续函数。

训练 SGD + 反向传播。非凸，局部极小，要多重初始化。

近年发现高维里鞍点 >> 局部极小，且多数局部极小泛化差不多。难点是鞍点停滞（动量法）。

（"线性∘线性=线性"这句一下就点破了为什么要有激活函数）
