# 核回归

线性模型 d(x)=w^T x 只能拟合直线。核方法把 x 映射到高维 φ(x)（含 x^3 x^2 x 1），d(x)=φ(x)^T w。

岭回归解 w = (Φ^T Φ + λI)^-1 Φ^T d。

关键恒等式：

(Φ^T Φ + λI)^-1 Φ^T = Φ^T (ΦΦ^T + λI)^-1

把 p×p 求逆换 n×n 求逆。p>>n 时不可行变可行。这就是对偶：权重空间（p 维）↔ 样本空间（n 维）。

ΦΦ^T 的 (i,j) 是 ⟨φ(x_i),φ(x_j)⟩，定义核 k(u,v)=⟨φ(u),φ(v)⟩，回归变 d(x)=Σ α_i k(x,x_i)。

核技巧：不显式计算 φ，只算核。满足 Mercer 条件就存在（可能无限维）φ。

三类核：多项式 (u^T v)^q、推广 (u^T v+1)^q、高斯 exp(-‖u-v‖²/2σ²) 无限维。

高斯泰勒展开含所有阶多项式，RKHS，显式构造不了但能算。

（对偶那个恒等式有点神奇，一个式子就换了求逆维度）
