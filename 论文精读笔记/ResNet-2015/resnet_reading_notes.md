## 一、论文核心问题

**为什么更深的网络反而更难训练？**

深度神经网络天然面临**梯度消失 / 梯度爆炸**问题。如果网络能够收敛，还会出现**退化问题（degradation problem）**：56 层的网络在训练集和测试集上的表现反而不如 21 层（见图 1）。这说明问题不是过拟合，而是深层网络难以通过逐层映射来学习一个“恒等函数”——如果连“什么都不做、把输入原样输出”都做不到，堆再多的层也是负优化。

## 二、核心方法：残差学习（Residual Learning）

### 2.1 基本思想

假设期望的映射是 $H(x)$。传统的网络直接让堆叠的层去拟合 $H(x)$。ResNet 的思路是：让堆叠的层去拟合**残差函数**

$$F(x) = H(x) - x$$

最终输出通过**跳连（skip connection / shortcut connection）**还原目标映射：

$$y = F(x) + x$$

其中 $x$ 是通过恒等映射（identity mapping）直接跳连过来的，$F(x)$ 是两层（或三层）卷积学出来的修正量。

### 2.2 残差块的输入、计算与输出（实例化）

以一个最基础的 `basic block` 为例，输入是一张特征图 $x \in \mathbb{R}^{B \times C \times H \times W}$：

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 主路 | `Conv → BN → ReLU → Conv → BN` | 两层 weight layer 计算 $F(x)$ |
| ② 跳连 | `identity` | $x$ 原封不动传过来 |
| ③ 相加 | $F(x) + x$ | 逐元素相加，要求形状完全一致 |
| ④ 激活 | `ReLU` | 对相加结果做非线性，输出 $y$ |

> **数值例子**：设输入 $x = [1.0, -0.5, 2.0, 0.3]$，两层网络算出 $F(x) = [1.36, -0.36, 1.81, 0.96]$，则跳连相加后 $F(x) + x = [2.36, -0.86, 3.81, 1.26]$，再经 ReLU 得到 $[2.36, 0, 3.81, 1.26]$。可以看到，即使主路贡献是负数（第 2 个元素），跳连仍能把 $x$ 的原值带过去——这正是“信息高速公路”的作用。

### 2.3 当输入输出形状不一致时

当特征图尺寸或通道数变化（如第一个 block 需要下采样），$F(x)$ 与 $x$ 形状不同，不能直接相加。解决方案：

- **方案 A（padding 零）**：通道数增加时，用零填充新增的通道。计算量最小。
- **方案 B（$1\times1$ 投影）**：跳连上接一个 $1\times1$ 卷积（stride=2 可降采样，输出通道可升维），把 $x$ 投影到与 $F(x)$ 相同的形状。实验表明投影方式略微提升精度。

$$y = F(x) + W_s \, x$$

其中 $W_s$ 是 $1\times1$ 卷积矩阵，只负责线性变换，不含非线性。

## 三、为什么残差连接能工作？

### 3.1 梯度传播

前向传播 $y = F(x) + x$，反向传播时：

$$\frac{\partial y}{\partial x} = \frac{\partial F}{\partial x} + I$$

即使深层主路的梯度 $\frac{\partial F}{\partial x}$ 趋于零（梯度消失），**跳连仍然保留了 $+I$ 这一项**，保证梯度至少能以恒等路径顺畅回传。这让训练上百层的网络成为可能。

### 3.2 学习目标的简化

残差 $F(x) = H(x) - x$ 通常比原始映射 $H(x)$ 更容易学习。如果最优函数接近于恒等映射（即“什么都不做”），残差函数就接近于零，网络只需微调极小的修正量。这大幅降低了深层网络的优化难度。

## 四、构建更深的 ResNet：Bottleneck 设计

### 4.1 动机

随着网络加深，每层都保持高通道数会导致计算量爆炸。ResNet-50/101/152 采用 **bottleneck block**，用“降维 → 空间操作 → 升维”的三层结构替代 basic block 的两层结构。

### 4.2 结构

以 256 通道为例：

```
输入 x (256通道)
  ├─ 1×1 Conv (256→64)  降维
  ├─ 3×3 Conv (64→64)   空间操作（主计算在64维低维空间）
  ├─ 1×1 Conv (64→256)  升维
  └─ F(x) + x           残差相加
```

### 4.3 计算量对比

- **Basic block**（两层 $3\times3$，256 通道）：约 $118$ 万乘加/像素
- **Bottleneck**（1×1 降维 + 3×3 + 1×1 升维）：约 $7.4$ 万乘加/像素

**约 16 倍节省**。省下的算力可以堆更深的层数，从而用“深度红利”弥补单块表达力的轻微损失。

### 4.4 关于“信息损失”的思考

降维再升维确实引入了两个副作用：

1. **低秩约束**：中间 64 维相当于对全 256 维卷积做低秩近似，单块理论表达能力弱于同通道的 basic block。
2. **信息损失风险**：降维压缩可能会丢掉部分信息。

**但为什么实际效果反而更好？**

- 降维投影是**端到端学习出来**的（$1\times1$ 卷积），它会自动保留对当前任务最重要的信息，而不是硬编码地截断主成分。
- 残差跳连 $+x$ 给信息提供了**备份通道**：即使主路在 64 维子空间里丢了什么，原始的 256 维信息仍能通过恒等映射传下去。
- **深度红利 > 单块损失**：ResNet-50（bottleneck，50 层）ImageNet top-1 约 76%，明显超过 ResNet-34（basic，34 层）约 73%。

> 值得注意的是，MobileNetV2 提出：在低维特征上做 ReLU 会造成信息塌陷（因为很多分量被置零）。它的改进是“反向残差 + 线性瓶颈”——降维后**不接 ReLU**。这说明 bottleneck 里的信息损失问题确实存在，但通过调整激活位置就可以缓解。

## 五、实验结果速览

| 网络 | 深度 | Top-1 (ImageNet) | 结构特点 |
|------|------|------------------|----------|
| ResNet-18 | 18 | ~69% | basic block |
| ResNet-34 | 34 | ~73% | basic block |
| ResNet-50 | 50 | ~76% | bottleneck |
| ResNet-101 | 101 | ~77% | bottleneck |
| ResNet-152 | 152 | ~78% | bottleneck |

关键发现：
- **图 1**：56 层 plain 网络 < 21 层 plain 网络（退化问题）
- **图 4**：34 层 ResNet > 18 层 ResNet（有残差连接后，深度再次成为优势）

## 六、阅读过程中的关键 Q&A

### Q1：图中输入是 $x$，直接进入 weight layer 的不应该是 $x$，而是 $h(x)$ 减去浅层网络中学到的 $x$ 吗？

**A**：这张图是对的，只是把 $F(x)$ 和 $H(x)$ 的含义搞混了。

- $x$ 确实是直接进入 weight layer 的输入。
- 两层 weight layer 组成的堆叠模块整体记为 $F(x)$，它学的是残差 $F(x) = H(x) - x$。
- $h(x)$（即 $H(x)$）是**期望的最终映射**，是事先未知、需要网络去逼近的目标。你不可能先用 $H(x)$ 减去 $x$ 再喂给网络——因为 $H(x)$ 正是我们想要得到的东西。
- 网络的真实输出是 $\text{ReLU}(F(x) + x)$，也就是 $H(x)$ 的近似。所以逻辑是：**以 $x$ 为输入学残差 $F(x)$，再通过跳连把 $x$ 加回去还原 $H(x)$**。

### Q2：残差连接具体如何操作？

**A**：核心就一步——**逐元素相加**。分两种情况：

1. **尺寸匹配**：$F(x)$ 和 $x$ 形状完全一致（同 batch、同通道、同空间尺寸），直接 $F(x) + x$ 即可。
2. **尺寸不匹配**：特征图尺寸或通道数变化时，跳连上用一个 $1\times1$ 卷积做投影 $W_s x$，使其与 $F(x)$ 对齐后再相加。

相加后再过一个 ReLU（或 BN+ReLU），得到本残差块的最终输出，作为下一个块的输入。

### Q3：Bottleneck 降维再升维不会造成信息损失吗？

**A**：会，但损失是可控且被设计接受的。

- **第一**，降维投影 $1\times1$ 卷积是**可学习的**，它会自动把对任务最有用的 64 维子空间学出来，而不是粗暴截断。
- **第二**，残差跳连 $+x$ 提供了信息备份——即使主路压缩丢了什么，原始高维信息仍能无损传递。
- **第三**，算力节省换来的深度红利，远超单块低秩约束带来的理论损失。实验也证明了这一点。
- **第四**，如果特别关注 ReLU 在低维破坏信息的问题，可以参考 MobileNetV2 的“线性瓶颈”改进：降维后的特征层**不使用 ReLU**，保留线性传递。

---

## 七、总结

ResNet 的核心贡献不在于某个复杂的模块，而在于一个极其简洁的洞察：

> **如果深层网络难以直接学习 $H(x)$，那就让它学习 $H(x) - x$，再用跳连把 $x$ 加回来。**

这个 $F(x) + x$ 的加法操作，看似简单，却同时解决了：
1. **梯度消失**：跳连提供恒等梯度通路
2. **退化问题**：深层网络至少不差于浅层（因为可以学到 $F(x)=0$）
3. **深度扩展**：bottleneck 设计让上百层网络的训练成为现实
