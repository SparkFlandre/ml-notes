# 问题研究学习

围绕一个核心问题进行的多课式深度学习笔记。每个子文件夹是一个完整的学习单元，包含笔记、示意图、闪卡、速查卡和复习日程。

## 学习单元

| 单元 | 主题 | 日期 | 闪卡数 |
|---|---|---|---|
| [scaling-law](./scaling-law/) | 大模型 Scaling Law：从幂律现象到推理时 scaling 与数据墙 | 2026-10-19 | 29 |

## 每个单元的标准结构

- `README.md` —— 单元概览与课程地图
- `notes.md` —— 完整学习笔记（TeX 公式 + 示意图）
- `flashcards.html` —— 自包含闪卡应用，浏览器打开即测，进度本地保存
- `cheatsheet.pdf` —— 打印版速查卡
- `scaling_law-schedule.ics` —— 间隔复习日程（可导入日历）
- `*.png` —— 配套示意图

## 学习方法

每个单元按"短时多课 + 间隔复习"组织：首次学习 4–5 课，之后按第 1/3/7/14/30/60/120 天用闪卡做主动回忆测验。
