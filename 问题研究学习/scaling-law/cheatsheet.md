# Scaling Law 速查卡

## 必须烂熟于心的要点

1. 损失与算力呈幂律：L = (Cc/C)^α + L∞，α≈0.076（Kaplan 2020）
2. log-log 坐标上是直线：log(L−L∞) = −α·log C + const
3. 可约损失减半 ⇒ 算力 ×2^(1/α) ≈ ×9000；α 越小回报越小
4. 双瓶颈：L = (Nc/N)^α_N + (Dc/D)^α_D + L∞（容量瓶颈 + 数据瓶颈）
5. 算力约束：C ≈ 6ND，预算固定时 N 与 D 此消彼长
6. 固定预算下 L 对 N 呈 U 形：太小容量不够，太大欠训练
7. 计算最优：约 20 token/参数，N_opt ∝ C^0.5（Chinchilla 2022）
8. GPT-3 是欠训练的：175B/300B token ≈ 1.7 token/参数；Chinchilla 70B/1.4T 反超 Gopher 280B

## 心智模型

- 一条直线（log-log）→ 可外推、可预言
- 一个地板（L∞）→ 收益递减但永不饱和
- 一条 U 形曲线 → 每个预算有唯一最优分配
- 一个约束（C≈6ND）→ N 和 D 必须同比例放大

## 常见误区

- 幂律会饱和？错，永不触及 L∞
- 模型越大越好？错，固定预算下过大=欠训练
- 数据不变可免费加大模型？错，C≈6ND 不允许
- α 大=回报大？对——α 越大，同样算力换来损失下降越多

## 关键数字

- α ≈ 0.076（对 C）；α_N ≈ 0.076，α_D ≈ 0.095（Kaplan）
- 20 token/参数（Chinchilla 最优）
- 2^(1/0.076) ≈ 9000（损失减半的算力倍数）


## 第三课：推理时 Scaling

9. 推理算力 ≈ 2×N×token 数："想更久"=多生成 token=多花算力
10. 推理任务准确率 ≈ a + b·log(推理算力)——又一条 log-log 直线（o1）
11. 长思维链三机制：拆解 / 自我检查 / 自我纠正（R1 的 aha moment），靠 RL 后训练习得
12. 交叉点：小模型想足够久可追平大模型 → 推理成本与模型规模解耦
13. 墙：对数收益递减；知识型任务无效；错误累积、上下文与延迟限制
14. 三代演进：堆参数 → 配数据（20 token/参数）→ 加思考时间


## 第四课：数据墙

15. 需求（每年约×3）追上存量（公共文本≈300万亿token）= 数据墙，估算约2026–2028
16. 存量≠可用量：高质量子集或只有1/10；重复训练≤4 epoch无损，>16 epoch白训
17. 撞墙后 (Dc/D_max)^α_D 成硬地板，堆参数变单引擎+欠训练
18. 逃生路线作用点：①合成数据=做大D（防 model collapse）；②多模态/私有=做大D；③推理时scaling=换轴；④提高利用率=改"汇率"
19. 统一视角：一轴撞墙就换轴——行业战略转移的钥匙


## 第五课：幂律的起源

20. 量化模型：特征频率 Zipf 幂律 → 尾巴质量仍幂律 → 残余损失幂律（背单词类比）
21. 流形维度：α ≈ 4/d，α 是数据复杂度的测量值，非宇宙常数
22. 共同思想：幂律由数据结构决定，模型只是转印
23. 实践含义：数据配方可以改变斜率
